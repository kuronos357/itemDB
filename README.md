# itemDB (物品・収納管理 PWA)

部屋の物と収納場所を情報空間（Notion）で追跡・同期するための個人用物品管理システムです。  
JIS X 0560:2025 (デジタルプロダクトパスポート/識別連携) のコンセプトを参考に、「物理整理＝キャッシュと物流フローの設計」という思想で設計されています。

---

## 🎯 主な特徴と仕様

- **偶奇による種別自動判定 (数字ID体系)**
  - **偶数 (`id % 2 === 0`)**: 物品 (Item)
  - **奇数 (`id % 2 === 1`)**: 場所 (Location)
  - 人間による可読性を考慮せず、テンキーやApple Watch等の予備入力が容易な純粋な数字連番を採用。
- **直感的な操作フロー**
  - **物品スキャン**: 物品名・ID・現在の置き場所を表示。「場所変更」を押して移動先の場所QRを読むと即座にNotionの現在地を更新。
  - **場所スキャン**: 場所名・置いてある物品一覧を表示。「編集」を押して物品QRを連続スキャンすると、所属物品なら**削除（取り出し）**、未所属なら**追加（格納）**を自動判定して即時更新。
- **音と振動のフィードバック**
  - Web Audio APIによる明瞭なシンセサイズ音（追加音・解除音・エラー音）と触覚バイブレーション。画面を注視しなくても物品の仕分け・棚卸が手元で行えます。
- **ゼロコンフィグな端末間セットアップ**
  - 設定用URL `?dbid={DBID}&api={SECRET}` をQRコード化してカメラで読み取らせるだけで、他のスマホやタブレットでも一瞬でセットアップ完了。

## 🏗️ Notion側のデータベース準備

Notion側で以下のプロパティを持つデータベースを1つ作成してください（物品・場所を同一DBで管理し、自己リレーションを張る構成を推奨します）。

| プロパティ名 | 種類 | 説明 |
|---|---|---|
| **名前** | タイトル (Title) | 物品名 または 場所名 |
| **ID** | 数値 (Number) | 偶数=物品、奇数=場所 |
| **現在地** | リレーション (Relation) | 同じデータベースを選択。物品が置かれている場所を指定 |
| **状態** | セレクト / ステータス | 「使用中」「保管中」「L1キャッシュ(机)」など（任意） |
| **メモ** | テキスト (Rich Text) | 補足情報（任意） |

> **重要**: 作成したデータベースの右上の「…」メニューから、インテグレーション（APIトークンを発行したコネクト）を必ず追加・共有してください。

## 🚀 デプロイとCORS対策

Notion公式APIはブラウザからの直接アクセスに対してCORSヘッダーを返さない仕様となっています。本システムは以下の2通りの公開方法に対応しています。

### 方法A: Cloudflare Pages (最も推奨・設定不要・高速)
本リポジトリには `functions/api/[[path]].js` が含まれています。
1. [Cloudflare Dashboard](https://dash.cloudflare.com/) にログインし、「Pages」を選択。
2. GitHubリポジトリ `kuronos357/itemDB` を連携してデプロイ。
3. これだけで自動的に `/api/...` 経由でNotion APIが中継され、CORS制約を完全に回避して快適に動作します（月10万リクエストまで無料）。

### 方法B: GitHub Pages
1. GitHubリポジトリの **Settings → Pages** を開く。
2. **Branch**: `main`, **Folder**: `/ (root)` を選択して保存。
3. `https://kuronos357.github.io/itemDB/` で公開されます。
4. アプリ内の設定画面（⚙️）で「通信方式」を **CORS Proxy (corsproxy.io)** またはご自身のカスタムWorkerに設定してください。

## 📱 使い方

### 1. 初期設定
1. アプリ右上の ⚙️ アイコンを開きます。
2. Notionの **APIトークン**（`secret_...`）と **データベースID** を入力して「疎通テストを実行」を押します。
3. 成功したら「設定を保存」を押します。
4. 「設定用QRコードを生成」を押して表示されるQRコードを別端末のカメラで読み取れば、他の端末にも即座に設定を複製できます。

### 2. 物品を場所に片付ける（物品起点）
1. 物品のQRコードをスキャンします。
2. 画面に物品の詳細と現在の置き場所が表示されます。
3. **「場所変更」** ボタンを押します。
4. 移動先の棚や箱の場所QR（奇数ID）をスキャンします。
5. 成功音とともにNotionの現在地が更新されます。

### 3. まとめて棚卸・収納する（場所起点の一括編集）
1. 保管したい場所（箱・引き出し・机など）のQRコードをスキャンします。
2. **「編集 (一括棚卸 / スキャン)」** ボタンを押します。
3. 物品のQRコード（偶数ID）を次々にスキャンします：
   - まだその場所にない物品 → **追加 (格納)** され、一覧に加わります。
   - 既にその場所にある物品 → **削除 (取り出し)** され、一覧から外れます。
4. 終わったら **「編集完了」** を押します。
